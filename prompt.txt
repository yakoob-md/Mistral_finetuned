
Dataset problems
❌ filler noise ({disfmarker}, uh, hmm)
❌ speaker tags (Grad F:, PhD C:)
❌ repeated words / stutters
❌ irrelevant conversational fragments
❌ inconsistent formatting
❌ weak/short outputs

You are a data preprocessing expert for LLM fine-tuning.

I have a dataset of meeting transcripts with fields:

* input (noisy transcript)
* output (summary)

The data contains:

* speaker tags (e.g., "Grad F:", "PhD C:")
* filler words (uh, um, hmm)
* noise tokens ({disfmarker}, {vocalsound})
* repeated phrases and stutters
* irrelevant conversational fragments

Your task is to clean and filter this dataset for high-quality fine-tuning.

---

# GOALS

Transform each sample into:

## CLEAN INPUT:

* remove speaker tags
* remove filler words and noise tokens
* remove repeated phrases
* normalize whitespace
* keep only meaningful content
* optionally truncate long text while preserving beginning + ending

## CLEAN OUTPUT:

* must be a concise paragraph
* must focus on key discussions, decisions, and outcomes
* must NOT include speaker names or dialogue
* must be at least 40 words
* must be coherent and structured

---

# FILTERING RULES

DROP samples if:

* output length < 40 words
* input is too noisy or mostly filler
* input-output pair is clearly misaligned
* summary does not reflect input content

---

# OUTPUT FORMAT

Return JSONL:
{
"input": "<cleaned_input>",
"output": "<cleaned_output>"
}

---

# IMPORTANT

* Do NOT hallucinate content
* Only clean and refine existing data
* Keep semantic meaning intact
* Ensure high-quality training signals

---

Now generate Python code that:

1. Loads JSONL dataset
2. Cleans input/output
3. Filters bad samples
4. Saves cleaned dataset

Make it efficient and ready for Kaggle.
